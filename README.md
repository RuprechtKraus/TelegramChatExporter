# TelegramChatExporter

Консольный экспортёр истории Telegram на C# / .NET 10 с WTelegramClient.
После входа показывает пронумерованный список личных чатов, групп и каналов.
Выберите номер — приложение сохранит доступную историю выбранного чата в JSON.

## Запуск

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```shell
git clone https://github.com/RuprechtKraus/TelegramChatExporter.git
cd TelegramChatExporter
```

Создайте Telegram API application на https://my.telegram.org/apps и получите **api_id** и **api_hash**.
Это реквизиты пользовательского приложения, не токен бота.
Сохраните их в .NET User Secrets (команды выполняются из корня репозитория):

```shell
dotnet user-secrets set "Telegram:ApiId" "12345678" --project src/TelegramChatExporter
dotnet user-secrets set "Telegram:ApiHash" "YOUR_32_CHARACTER_API_HASH" --project src/TelegramChatExporter
dotnet user-secrets set "Export:Directory" "D:/TelegramExports" --project src/TelegramChatExporter
dotnet run --project src/TelegramChatExporter
```

При первом запуске введите телефон с кодом страны, код входа и пароль 2FA (если включён).
Код и пароль не отображаются при вводе в интерактивной консоли.
После авторизации выберите чат по номеру; `0` завершает программу, `Ctrl+C` отменяет работу.
Для экспорта другого чата запустите приложение снова; сохранённая сессия позволяет повторно не вводить код.

## Настройки

`src/TelegramChatExporter/appsettings.json`:

```json
{
  "Telegram": {
    "ApiId": 0,
    "ApiHash": "",
    "PhoneNumber": "",
    "SessionPath": ""
  },
  "Export": {
    "Directory": "exports"
  }
}
```

Можно задать реальные `ApiId` и `ApiHash` непосредственно здесь. Не коммитьте их в публичный репозиторий.
Для локальных JSON-настроек можно создать рядом `appsettings.Local.json`: он исключён из Git.
User Secrets хранятся вне проекта и применяются также при запуске Release; это локальное хранилище .NET, а не GitHub Actions Secrets. User Secrets не шифруются.

Приоритет (последний источник побеждает):

1. `appsettings.json` рядом с исполняемым файлом; при сборке копируется из проекта.
2. `appsettings.Local.json` рядом с исполняемым файлом; при сборке копируется, при publish — нет.
3. .NET User Secrets.
4. Переменные окружения с префиксом `TCE_`, например `TCE_Telegram__ApiId`, `TCE_Telegram__ApiHash`, `TCE_Export__Directory`.

Относительные пути экспорта и явно заданной сессии считаются от текущего рабочего каталога.
Папка экспорта создаётся автоматически. `PhoneNumber` необязателен: иначе номер запрашивается в консоли.
По умолчанию сессия хранится в `TelegramChatExporter/telegram.session` внутри системной папки LocalApplicationData
(на Windows обычно `%LOCALAPPDATA%`). Чтобы сменить аккаунт, закройте программу и удалите сессию либо задайте другой `SessionPath`.
Сессия предоставляет доступ к аккаунту: не публикуйте её. Сессии, локальные настройки и стандартная папка `exports/` исключены из Git.

## Результат

Имя: `Название чата_2026-11-05_18-30-45-1234567.json`.
Дата/время в имени — локальное время начала экспорта; доли секунды уменьшают вероятность совпадений.
Недопустимые символы в названии заменяются на `_`, длинные названия сокращаются. Существующие файлы не перезаписываются.

```json
[
  {
    "time": "2026-11-05T15:30:00+00:00",
    "sender": "Иван Иванов",
    "text": "Привет!"
  }
]
```

- `time`: время отправки сообщения в UTC, ISO 8601.
- `sender`: имя пользователя/название канала; если имя недоступно, тип и ID отправителя. Подпись автора поста канала добавляется в скобках.
- `text`: обычный текст или подпись к медиа, без форматирования Telegram. Для медиа без подписи — пустая строка.
- Порядок: **от новых сообщений к старым**. JSON пишется потоково; история целиком не хранится в памяти.
- Пустой чат даёт `[]`. Служебные события (вступления, закрепления и т. п.) пропускаются.
- Фото, видео, файлы, реакции и вложения не скачиваются. Секретные чаты не поддерживаются.
- Экспортируется только история, доступная текущему аккаунту; удалённые/скрытые сообщения не восстанавливаются. Старая история базовой группы до миграции в супергруппу отдельно не объединяется.
- При ограничении FLOOD_WAIT приложение ждёт указанный Telegram срок. Прогресс выводится после каждой страницы.
- Во время записи используется `.partial`; готовый `.json` появляется только после успешного завершения. При обрабатываемой ошибке/отмене временный файл удаляется. После аварийного завершения процесса оставшийся `.partial` можно удалить вручную. Повторный запуск начинает экспорт заново.

## Проверки

```shell
dotnet build TelegramChatExporter.slnx --configuration Release
dotnet test TelegramChatExporter.slnx --configuration Release
```

GitHub Actions выполняет сборку и тесты на Windows и Linux без реквизитов Telegram.
Тесты проверяют JSON, Unicode, UTC, пустой чат, очистку при ошибке/отмене, безопасные имена файлов и определение отправителя.
Живую авторизацию и доступ к истории нужно проверить локально со своим аккаунтом.
